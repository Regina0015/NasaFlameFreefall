# Data catalog — snapshot tables

Generated by `scripts/build_snapshot.py` from `scripts/contract.py`. Do not edit by hand.

## tests

| Column | Type | Unit | Meaning |
|---|---|---|---|
| `test_id` | VARCHAR |  | Unique id: investigation, table index and row, e.g. PSI-25-T0-R1 |
| `investigation` | VARCHAR |  | PSI investigation id, e.g. PSI-25 |
| `source_table` | VARCHAR |  | Original PSI CSV file name the row comes from |
| `source_row` | INTEGER |  | Row in that CSV; the first data row after the header is 1 |
| `fuel` | VARCHAR |  | Fuel or sample material, as written in the source table (whitespace collapsed) |
| `phase` | VARCHAR |  | solid, droplet, gas or smoke |
| `geometry` | VARCHAR |  | Sample or burner geometry when the table states it (rod, film, fabric, droplet, burner); else empty |
| `o2_pct_min` | DOUBLE | % O2 | Lowest oxygen level of the row, percent by volume or mole (treated as equal) |
| `o2_pct_max` | DOUBLE | % O2 | Highest oxygen level of the row; equals o2_pct_min when the row has one value |
| `pressure_atm_min` | DOUBLE | atm | Lowest ambient pressure of the row |
| `pressure_atm_max` | DOUBLE | atm | Highest ambient pressure of the row |
| `flow_cm_s` | DOUBLE | cm/s | Air or inlet flow velocity, when the table gives one value |
| `diluent` | VARCHAR |  | Gases other than O2 (e.g. N2, N2+CO2, He), or the table's own mixture text |
| `gravity` | VARCHAR |  | microgravity or earth |
| `outcome` | VARCHAR |  | Result of the test as the table states it (e.g. extinction), lowercased; empty if none |
| `other` | VARCHAR |  | JSON object: other measured or controlled values, keyed by original column name |
| `raw` | VARCHAR |  | JSON object: every original cell of the row, keyed by original column name |
| `field_sources` | VARCHAR |  | JSON object: normalized field name -> original column name it was read from (several are joined with ' | ') |
| `problems` | VARCHAR |  | Cleaning notes for this row, joined with '; ' |
| `scope` | VARCHAR |  | psi for NASA data; user:<name> for a user's dataset |

## Caveats

- Oxygen is stored in percent. Mole fraction and volume fraction are treated as equal (ideal gas).
- A row can hold several values (FLEX-2 condition matrix, BRE test days): o2/pressure min and max then differ, and `problems` says so.
- FLEX headers lost their subscripts in PSI's file: `O` = O2, `N` = N2, `CO` = CO2 (FLEX tested CO2 and He as diluents).
- CFI-G inverse flames: the O2 value is the burner (oxidizer) stream, not the chamber.
- BASS-II, Saffire-II, BRE and SAME-R tables do not give a pressure; those cells are empty.
- Values outside physical ranges (O2 0-100 %, pressure 0-50 atm, flow 0-1000 cm/s) are left empty and noted in `problems`; the original cell stays in `raw`.
- Row numbers: the first data row after the header is 1. Column names are the CSV header with repeated whitespace collapsed.
