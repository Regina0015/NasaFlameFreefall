# Geographic boundary

## nuevo-leon.geojson

- Content: the outline of the Mexican state of Nuevo Leon (admin-1, a state boundary, not a city boundary), 695 points,
  one polygon. Coordinates are longitude, latitude (WGS84), rounded to 5 decimals. Only this one feature was kept.
- Source: Natural Earth, "Admin 1 - States, Provinces" at 1:10m scale (feature iso_3166_2 = MX-NLE), from
  https://github.com/nvkelso/natural-earth-vector (geojson/ne_10m_admin_1_states_provinces.geojson).
- License: public domain (https://www.naturalearthdata.com/about/terms-of-use/).
- Downloaded: 2026-11-15. The outline is generalized for a 1:10m map and is for illustration, not for surveying.
